# Irving He · Personal Website

何子辰的个人简历网站，支持中文 / English、浅色 / 深色主题。

## GitHub Pages

Repository: `HzcIrving/HzcIrving.github.io`

Publishing source: **Settings → Pages → Deploy from a branch → main → /(root)**.

The site is a static website and requires no build step. After Pages is enabled, pushes to `main` publish automatically.

## Local preview

```sh
python3 -m http.server 8000
```

Open http://localhost:8000/ in a browser.

## Editing

- `index.html`: biography, work, education, publications, honors.
- `style.css`: layout and themes.
- `resume.js`: language, theme, navigation, and pointer effects.
- `assets/`: original publication figures, portraits, and organization logos.

Publication figures retain their captions and source links. Rights belong to the respective authors and publishers.
